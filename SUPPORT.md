# Support

VPS Doctor is maintained as a community open-source project and does not provide an emergency response service.

For incorrect findings or runtime errors, open a bug report with the VPS Doctor version, operating system, rule ID, and the smallest necessary redacted evidence. For usage questions, open a GitHub Discussion after discussions are enabled on the public repository.

If a server may be compromised, stop making speculative changes, preserve evidence, rotate credentials from a trusted machine, contact the hosting provider, and engage a qualified incident responder. Do not post sensitive incident logs publicly.
